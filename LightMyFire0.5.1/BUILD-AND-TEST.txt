LIGHTMYFIRE 0.5.3 - BUILD AND TEST

1. Close Valheim.
2. Double-click BUILD-AND-INSTALL.bat.
3. The script verifies the exact production AssetBundle from your known-good 0.5.0 DLL.
4. It forces a fresh 0.5.3 DLL build against your CURRENT Valheim/Jotunn/BepInEx assemblies.
5. It validates and creates the Thunderstore package, backs up your old local DLL, and installs the new DLL.
6. Install the SAME 0.5.3 build on the dedicated server before connecting.
7. Start the server, then Valheim.

The generated Thunderstore upload is:
artifacts\R4V9N1-LightMyFire_Coal_Resin-0.5.3.zip

Startup should show:
Loading [LightMyFire 0.5.3]
